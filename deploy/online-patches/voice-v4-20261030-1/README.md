# V4 语音球与文字输入

版本：`voice-v4-20261030-1`。在已上线的卡片传送版本基础上，接入用户验收通过的 V4 输入方案。

- 默认显示现有配色的 72px Siri 球，小球旁提示说“Hi，Vivic”唤醒。唤醒后放大约 1.6 倍，倾听期间不显示用户转写。
- 继续使用现有 PCM 录音、静音分段、`/api/transcribe` 和指令执行接口。识别到以“Hi，Vivic”开头的语句后才能执行；仅唤醒词时等待下一句，唤醒词与指令连说时直接执行后半句。未唤醒的普通说话不会提交指令。
- 保留文字模式原有单行胶囊框、加号、图片和文件菜单。键盘按钮切换文字，原麦克风位置切回语音；草稿和附件不随切换被销毁。
- Vivic 真实反馈继续显示在输入区上方。既有确认、错误、卡片传送和展示窗口逻辑保留。
- 以当前 v59 为唯一 `app-runtime.js`，启动脚本直接导入该模块，历史版本文件只做兼容导出，避免工作区与教程引用不同 Context。
