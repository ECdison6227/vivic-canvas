# Vivic UI 逐项复核与修复记录

核验日期：2026-10-28。公开地址：https://vivic.edsionc.top/control 。

用户反馈属实：此前的修改没有全部存在于当前线上页面。本次已修复公开页面实际使用的组件，并对真实线上响应完成浏览器交互核验。

## 原因与修复

1. 之前修改存在于容器可写层，后续部署替换容器后丢失，公开页面重新引用旧的 `settings-20261028-1` 资源。
2. 当前入口实际动态加载 `ControlApp-TutorialEntry20261028.js`。只修改旧的 `ControlApp-PlatformKeyLock20261027.js` 不会改变正在使用的设置页面。之前对此核验不完整。
3. 本次追踪公开 HTML → 入口 → 实际组件，修复 TutorialEntry，保留其中已有的教程功能。共享背景、存储和展示组件一并补齐。
4. 完整前端改为由 Nginx 从服务器持久化目录提供；API 继续使用原后端。后端容器被替换时，前端修复不再随容器可写层丢失。主页使用 `Cache-Control: no-store`，各模块统一引用一个入口，防止混用入口造成登录历史白屏。
