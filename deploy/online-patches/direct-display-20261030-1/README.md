# 展示窗口直接显示空间

版本：`direct-display-20261030-1`。

用户要求展示窗口打开时不要浮现开场小球，直接展示当前空间。本次修改实际加载的 `DisplayApp-DkgZz97I.js`：

- 待机和唤醒阶段不再渲染开场球体。
- 完整画布快照就绪后立即显示真实画布，不再等待全局阶段从 `AWAKENING` 转为 `WORKSPACE`。
- 首次就绪后保留画布，避免短暂控制页断连导致画布消失。正常工作期间的真实交互反馈继续沿用原有实现。

保留已上线的共享背景、实时配色/光效同步、加载背景保护及背景菜单字体修改。不修改启动入口、后端、数据库或用户数据。

## 验证

用独立模拟账号和便笺画布，通过真实「展示窗口」按钮打开弹窗；逐动画帧检查开场球体，并录制实际页面画面。验证实际便笺直接显示、唤醒阶段仍显示画布、刷新、延迟 1800ms 会话请求后重开、手机宽度、使用页刷新和空白空间。线上验收使用公开域名真实静态资源，不替换 HTML、JS 或 CSS。

`*-verification.json` 记录候选/线上结果；`*-pixel-verification.json` 使用实际截图和录屏背景像素检查背景修复得到保留。测试没有创建生产账号或操作真实用户数据。

## 发布和回退

新完整发布目录复用未修改资源的硬链接；修改的 HTML/JS 均使用临时文件原子替换以断开原 inode。发布前检查磁盘空间及并行版本、HTML、JS、Nginx 配置的一致性。

`publication.json` 中 `previous` 为回退目录。回退前确认当前指针仍属于本版本，再用临时软链接原子切回 `previous`，原子恢复 `nginx-before.conf` 至原配置路径，执行 `nginx -t` 后 `nginx -s reload`。不重启后端。

`patch/`、本说明及验收资料保留供每日 GitHub 归档。现有 GitHub 连接缺少写入权限，本次不清理旧发布，待维护者归档后处理。
