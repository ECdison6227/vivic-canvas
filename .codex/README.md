# Codex Local Environment

Use the ChatGPT desktop app's local-environment settings to generate and maintain project setup scripts and common actions here. Commit shareable configuration so worktrees can reproduce the environment.

Do not place secrets or machine-specific credentials in this directory. Keep setup deterministic and make actions call repository-owned scripts rather than duplicating long command sequences.

Official guidance: https://learn.chatgpt.com/docs/environments/local-environment
