# 中继部署边界

这里只提供可审查的运行配置，未部署公网服务、未申请证书或购买云资源。`nginx.conf.example` 也未在真实 nginx 上执行验证。

## 服务要求

- Node.js 22 或更新版本；独立模块依赖安装后运行 `pnpm --dir contrib/mobile-console relay`。
- 中继上游固定监听 loopback，默认 `127.0.0.1:8791`，WebSocket 路径严格为 `/relay`，不能附加查询字符串。原本机 Vivic API 的监听、Origin 和 token 均无需调整。
- 开发环境允许 `ws://127.0.0.1:8791/relay`，默认 Origin 白名单仅 `http://localhost:5174` 与 `http://127.0.0.1:5174`。这只是本机明文测试，不能称为远程 WSS 验证。
- 公网运行设置 `VIVIC_RELAY_PUBLIC=1`，配置真实 HTTPS 控制台 Origin，并由可信 nginx/同类反向代理提供有效证书的 HTTPS/WSS。手机、电脑都主动连接此 WSS；同局域网仍需要互联网和中继。

## 配置

| 环境变量 | 作用 |
| --- | --- |
| `VIVIC_RELAY_ADMISSION_SECRET` | 必需，32–256 字符的独立随机接入密钥；由运维通过受控进程环境注入。只在电脑端输入，不给手机。不能使用模型 Key、Pi/OAuth 或现有本机 API token。 |
| `VIVIC_RELAY_ORIGINS` | 逗号分隔的准确 Origin，无路径、通配符或尾部斜杠；公网必须为 HTTPS。 |
| `VIVIC_RELAY_PUBLIC` | 公网模式设为 `1`，强制 HTTPS Origin 及代理覆盖后的 `X-Forwarded-Proto: https`。 |
| `VIVIC_RELAY_HOST` | 默认 `127.0.0.1`，仅允许 loopback；不接受 `0.0.0.0`。 |
| `VIVIC_RELAY_PORT` | 默认 `8791`，由 TLS 代理转发。 |

不要把真实密钥写入源码、示例配置、命令历史或提交的文档；本模块不提供默认接入密钥。电脑首次接入后获得专用的随机会话 token 和一次性配对码。token 只保存在客户端内存，刷新页面后须重新配对或重新接入，不能承诺跨刷新凭据恢复。会话最多 8 小时，一次性配对码 120 秒过期，电脑可生成新码；中继重启清除全部会话。

## TLS、可见数据与保留

TLS 在反向代理终止，代理到本机 Node 服务为 loopback 明文。可信中继能够看到配对凭据、控制文字、最小画布元信息、结果和状态；这不属于端到端加密。中继不保存画布、不调用模型、不执行 Action，不把文字或画布内容写入磁盘或应用日志。会话/身份/去重之外的协议结果由电脑 connector 管理；中继没有离线指令队列。电脑离线时明确拒绝转交，连接恢复不会自动重放写操作。

Node 服务仅打印监听地址、协议版本和运行模式，不打印 token、配对码或消息内容。示例 nginx 关闭访问日志，错误日志仅 critical；由部署者规定错误日志的权限、轮换和最短保留时间。不要启用 WebSocket 内容追踪、请求体日志或在包含配对码的浏览器页面上采集公开截图/trace。

服务端限制 32 KiB 帧、100 个会话、每会话 4 个手机、256 个连接、单连接每 10 秒 100 条消息和同真实连接源每分钟 20 次鉴权尝试。反向代理后鉴权限流按 loopback 上游来源合并，这是小规模原型限制；大规模部署需独立评审可信代理身份及配额方案。原型没有账号/计费/多租户管理或全量云画布存储。

## 运维检查与回退

1. 在服务器本机检查 `http://127.0.0.1:8791/healthz` 返回 `service: vivic-mobile-relay`、`protocol: 1`。HTTP 200 本身不能证明服务身份。
2. 用真实 HTTPS 控制台连接 WSS，确认非法 Origin、错误/过期/已用配对码、撤销 token 均失败；不把本地反向代理头模拟测试当作真实 TLS 部署。
3. 电脑关闭 owner 时手机应显示不可控制；恢复连接先同步状态/查询结果，不能将 relay ACK 当执行成功。
4. 回退时在电脑撤销会话，再停止专用中继与移除专用 nginx 配置。原 Vivic 本地控制、IndexedDB 与 Display 不应依赖中继，原服务无需重启。

真实手机同局域网、移动网络/异地、锁屏、休眠及真实 WSS 证书链须另行记录。此配置文件不提供这些验收证据。
