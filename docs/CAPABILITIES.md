# 当前能力与边界

本地单人版，2026-10-22。用户文字最终只转换成经过校验的画布动作和数据。

| 能力 | 目前支持 | 使用条件 |
| --- | --- | --- |
| 本地文字指令 | 计时器、事项/计划提醒、待办、卡片定位/聚焦/删除、显示全部/恢复视图 | 支持的规则表达无需模型；复杂或不明确要求会澄清 |
| 画布操作与卡片传送 | 用户页和展示页均有卡片传送门；支持同页拖入传送区、一键双向传送、聚焦、显示全部和恢复视图 | 同源标签页/窗口；保持主控用户页打开。展示端由主控校验确认，不自行写入画布 |
| 场景整理 | 21个内置场景，论文/周计划/进度/阅读/月历等；便笺与既有卡片编辑 | 自然语言复杂整理需连接模型；数字/日期/来源需要依据 |
| 数据图表 | 用户给出的表格、折线/柱状/饼图与受控转换 | 提供完整数值；摘要数据不能冒充完整原卡 |
| 天气与资料 | 当前天气、公开资料检索、受控HTTPS页面读取 | 相应真实服务可达；保留来源，不编造实时信息 |
| 旅游DEMO | 酒店/航班/景点结果卡、选中结果、用户备注、按原条件刷新 | 本地服务即可；示例「下周去杭州住两晚，预算500」无需模型 |
| 声明式扩展卡 | 导入JSON卡片包、隔离Test Space、参数编辑、安装恢复、按卡名请求模型创建 | 严格支持的Schema/组件子集；内容hash固定安装身份 |

旅游默认使用虚构DEMO数据，不连接飞猪，不提供真实价格、库存、交通时刻或订单。真实适配器拿到工具协议与脱敏返回证据后才能集成，界面在此之前保持 DEMO。缺日期、晚数或出发地会询问；模糊日期保持原话，不猜具体入住日。

不支持预订、下单、付款、任意命令执行、任意代码/React插件、包内网络调用、第三方MCP通用宿主或模型自行联网。扩展包只能组合受控JSON组件与数据；模型不能修改服务结果和来源，也不能覆盖被截断的画布原文。

105条离线评测验证的是预期提取结果经过真实校验与构建，未测试真实模型理解准确率或真实飞猪服务；详细命令与边界见 [评测记录](verification/intent-evaluation-20261021.md)。
