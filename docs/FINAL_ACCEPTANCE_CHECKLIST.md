# Vivic 一期完整测试清单：从首次打开开始

版本日期：2026-10-16。顺序：**先收尾修复 → 按组测试现有全部功能 → 修复反馈并复测 → 再逐项做二期**。

最新：用户已要求 Agent 直接复测，结果另记 [逐句输入记录](archive/2026-10/USER_TEST_RESULTS_20261016.md) 和 [本轮修复](archive/2026-10/user-feedback-20261016.md)。下表“待测”仍指本人现场验收，不能与 Agent 独立浏览器测试混为一谈。到时提示音现在独立于 TTS；关闭字幕不再关闭提醒。

这份清单供本人实际操作和记录，不表示下面的人工项目已经通过。需要补做现场项目时可以分组进行，一组有问题就先处理，不需要一次做完所有组；本轮 Agent 真实复测独立记入上方的新报告。[一期收尾报告](archive/2026-10/finalization-20261016.md) 保留此前验证事实。

## 使用与记录

- 结果填“通过 / 失败 / 待条件 / 暂缓”，默认均为 **待测**。不支持的设备能力要记具体浏览器/原因，不能直接算通过。
- 用独立浏览器用户配置或明确的 TEST 环境，画布命名 `TEST-一期验收-日期`。不要为模拟新用户删除原有数据。无痕窗口可能丢弃持久化数据，恢复/模型缓存项目请用保留存储的独立配置。
- 日常入口为 `http://localhost:5175/control`；同一浏览器打开它的 Display，域名保持一致。5174/8788 为自动化专用，不与手测窗口混用。已有服务不用重启；全新安装才按 README 安装和启动。
- 5173 当前属于其他项目；旧入口已修正。端口改变会隔离浏览器存储，旧端口画布未删除，也不会自动迁入 5175；如需旧数据，另行迁移，不清除浏览器数据。
- TTS 默认关闭，先测全部文字功能。真实开麦/试听只在你本人选择做第 12–14 组时操作；Agent 自动化仍静音、使用合成输入或替身。
- 画布数据属于浏览器；后端模型连接属于当前本机进程。新浏览器配置可能没有画布，但后端仍已有连接，这不等于数据或账号串了。后端重启会丢失 StepFun 内存 Key。
- 从连接组开始，真实模型/搜索/图片/语音会使用你的账号能力和额度，只发送测试内容。已有 GPT 授权可恢复，**不为了这轮测试重复新登录或注销 Pi**。
- 每组后记录输入原文、实际结果、预期、浏览器/模型和截图。遇到错删、丢数据、数值错误、别的画布被修改，保留现场先反馈。
- 每组新建 `TEST-组名` 画布；除明确写“接着”的步骤外，可再用新的 TEST 画布隔离同名卡片/提醒，避免上一组数据改变指代。不要用清除全部本地数据来做每组清场。
