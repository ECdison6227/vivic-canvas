# 本地运行与扫码远控正式接线

2026-10-22 用户明确授权：保留已修复的 #13/#14，本地安装器与决策模型可以进入产品；手机扫码即可配对接入，可使用本人服务器部署中继。UI 设计由独立 Hark Android 研究任务负责，本轮复用已有组件，只补必要功能与状态。此安排取代旧文档中“手机产品接线暂停”的限制。

## 本轮范围

- 新建维护者集成分支 `feat/local-runtime-mobile-bridge`，基于平台实现，保留 #13/#14 已验证修复；审阅 #18 的状态提示后择取相关实现。
- Windows x64 受控本地运行：固定 llama.cpp 引擎与 Qwen GGUF 模型清单、来源/大小/SHA-256、准备进度/取消、启停/健康/超时、所属进程回收、离线推理与真实门控。模型结果仍经核心候选评分与语义/目标校验，不制造生成式信心或扩大 Action 权限。
- 可分发本地运行包：包含固定 Node 运行时、后端生产依赖、Web 构建及双击启动/停止入口；用户显式准备本地模型，保留启动路径和版本信息。
- 手机正式接线：独立 `/mobile` 入口，不启动第二个 owner；扫码一次性配对、启停/撤销、文字/固定/切换、取消与未知结果；每次实际提交前检查会话、owner、画布与版本，结果等待本地保存确认，沿用 Display 同步。
- 服务器独立中继：使用已有 HTTPS 域名的独立路径、loopback 服务与现有反向代理。部署前验证构建/Origin/权限与回退，使用合成数据验收，不公开本地 API/用户画布/模型 Key。
