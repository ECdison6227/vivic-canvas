# 卡片导入与 Vivic Test Space

2026-10-20 用户确认的产品流程：设置页导入卡片包 → 解析/校验 → 在 Vivic Test Space 弹窗预览与试跑 → 确认安装。本文是实现与验收要求；当前界面、包解析器与试跑宿主尚未实现。

相关：[包与宿主设计](CARD_EXTENSION_DESIGN.md)、[单卡设计表](cards/CARD_SPEC_TEMPLATE.md)、[首轮任务](tasks/card-platform-first-sprint.md)。

## 用户流程

1. 在 `/control` 设置页的“卡片管理”选择“导入卡片包”。不在 Display 增加安装菜单。
2. 选择本地包，显示文件名和解析进度。先做静态解析/校验，不在解析阶段执行包内代码或调用外部服务。
3. 展示校验结果：包身份/版本、兼容性、卡片类型、依赖能力、错误和提示。阻断错误应能定位到字段/文件，并说明如何处理。
4. 校验通过后进入 **Vivic Test Space** 弹窗。复用现有 Radix Dialog 与产品视觉，支持键盘关闭和焦点回到导入入口；它是产品内弹窗，不需要启动新的桌面程序。
5. 用包内已校验的示例预览，明确标注 DEMO；可以修改合法参数、切换 User/Display、深浅色及背景配色、试不同内容状态。
6. 点击“试跑”。默认用隔离测试数据；用户选择已有连接并明确切换真实数据后，才调用已允许的服务能力。没有连接时说明原因，仍可以看 DEMO 预览。
7. 用户检查结果，点击“安装卡片”。安装完成后卡片定义进入本地可用目录；之后按需创建正式实例，试跑中的数据不自动加入真实画布。

安装按钮不是“所有功能已由 AI 证明正确”的保证。界面分别显示结构校验、样例运行和真实连接结果；人工可以检查样式和交互。依赖外部连接的卡片，如未完成 live 验证应显示“真实连接未验证”，不能显示全部通过。

## 解析与校验

- 固定 v0.1 包格式、兼容版本和一个受支持渲染路径；不支持的包明确拒绝，不能因为有 `ui` 文件就直接执行。
- 检查文件/资源路径、大小/数量限制、必须文件、重复 ID/字段、manifest、数据/配置/状态 Schema、示例和动作声明。使用压缩包时还需限制解压后总量并拒绝越界路径；具体数值由包协议明确。
- 检查请求的组件、动作和服务能力是否在宿主支持范围；包不能自行增加模型/系统执行权限。
- 静态校验结果绑定包内容身份和版本。重新选包后使旧结果、旧试跑、旧“可安装”状态失效，避免用 A 包的通过结果安装 B 包。
- 安装边界重新核对正在安装的内容、兼容性及必要检查，不能只相信前端布尔值。注册要能回滚，失败不留半安装状态。

## Test Space 的隔离与退出

- 使用独立测试会话、内存状态和数据作用域；不复用用户真实画布的 owner、ID、广播频道或持久化位置。
- 样例试跑不请求真实模型/网络；真实连接试跑须选择服务并按允许能力调用。真实响应进入标准化/事实校验后再展示，凭据不送进卡片。
- 运行失败、无数据、缺字段、过期、取消有可辨认的结果。重试生成新请求标识，迟到结果不能覆盖新一轮参数或预览。
- 关闭/换包/重置时取消在途请求、停止计时器并释放 preview/媒体等资源；晚到消息不能安装卡片或写入用户状态。
- 当前产品范围优先试跑查询/展示/可撤销的测试编辑；订购、支付、发消息等外部副作用不因“试跑”而获得授权。
- 声音/麦克风仍按仓库既有约定关闭；不要为了测试主题或布局访问个人数据。

## 前后端交接界面（责任约定，不是已实现 API）

| 动作 | 输入/返回必须说明的内容 |
| --- | --- |
| 解析并校验 | 包文件 → 包内容身份、兼容性、错误列表、元信息与受支持预览描述 |
| 创建测试会话 | 已校验的包引用、测试模式 → 会话 ID 与独立实例状态 |
| 修改参数 | 会话、预期版本、参数 patch → 有效值或字段错误；触发查询则返回新的运行标识 |
| 试跑/取消 | 会话、参数版本、DEMO/真实连接引用 → 有来源的结果或错误；取消与迟到消息语义明确 |
| 安装/退出 | 精确的已校验包引用与内容身份，或会话 ID → 安装结果/清理完成 |

维护者在 CORE-01 将这些约定固化成实际 TypeScript/Zod 协议和 fixture。前端通过传入的服务接口做 UI，先用 mock 演示各状态；mock 的通过标志不参与正式安装。后端适配无需依赖弹窗内部实现。

## 验收场景

- [ ] 有效包可校验并预览；损坏/不支持/路径越界/示例不合法的包被拒绝。
- [ ] 缺必需字段时错误可定位；重新选包后旧校验与试跑结果清除。
- [ ] 参数按规范可编辑，服务事实不能通过普通参数编辑改写。
- [ ] User/Display、深浅色和 12 背景配色下正常；长文本、缺图、空/错状态可查看。
- [ ] 试跑/取消/重试/关闭不会写入真实画布或留下活动任务；迟到响应无副作用。
- [ ] DEMO、真实成功、真实未验证、连接失败分别展示，不混称已通过。
- [ ] 未通过阻断校验不能安装；安装精确的已校验包，同 ID/版本重装与升级策略明确。
- [ ] 安装后不改源码/不重新构建即可创建该定义的实例，刷新恢复正常；禁用/缺包不丢用户数据。

可先交付 UI 状态原型与隔离 fixture 预览，再接真实解析/运行/安装能力；这些阶段分别验收，不能把原型完成写成完整导入功能上线。
