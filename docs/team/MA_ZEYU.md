## 提交与验收

开发完成后使用 [提交 PR 提示词](WORKFLOW.md)，填实际 Issue 链接；每个任务一个 PR，启动器另分支，不把全部后台重写混在一起。

程序退出码 0 或评测跑完只表示流程成功，不代表决策准确率达标。提交时区分真实模型、模拟传输、不同设备、首次加载与温热性能；新模型/跨平台测试不能借用旧 Kev 成绩。真实用户数据、服务密钥和模型权重不提交。

程佳锐验收独立结果后，再接入产品状态/请求链路并做实际体验验证。你的原型交付无需等前端，但最终全链路验收有明确的集成阶段。
