# 官网当前仅开放内测申请

2026-10-17 用户明确要求官网目前只收集内测申请，不从官网进入 Vivic 体验。

- 表单提交成功后留在原页面，显示「申请提交成功！内测开放时，我们会通过邮件通知你。」
- 无论接口返回 `pending` 还是 `approved`，都不自动打开 `/vivic/app/`。
- 页头、首屏与结尾的「进入 VIVIC」按钮统一显示为灰色，使用原生 `disabled` 与 `aria-disabled`，不响应点击或键盘激活。
- 申请入口仍可使用；提交中防重复操作，成功后显示「已申请」，失败时允许重试。
- 成功后表单结束忙碌状态，便于辅助技术读取提交结果。
- 保留既有申请 API、内测审核、画布服务和底部四个二维码。

本次基于当前线上单文件构建修改，避免较早的源码构建覆盖已上线的内测登记流程。可重复应用：

```sh
python3 scripts/update-landing-beta-only.py current-index.html updated-index.html
```

发布前备份线上 HTML 并核对源文件 SHA-256，再原子替换。后续重新构建官网时，需要保留此申请模式；开放体验后再统一调整入口行为。

验证覆盖桌面和手机布局，模拟申请接口的 `approved`、`pending`、错误响应，以及无效邮箱。检查提交后的页面地址、成功提示、防重复提交、错误重试、三个入口的禁用状态、四个二维码和横向溢出；模拟响应不向真实申请名单写入测试邮箱。
