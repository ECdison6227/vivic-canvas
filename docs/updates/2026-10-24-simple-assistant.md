# 简洁助手收口：三端、卡片和 Jev

本轮由三个子 Agent 分别负责界面、卡片和决策接口，主 Agent 完成宿主执行、语音/球状态、真实服务验证与集成。保留此前未提交工作；没有推送 GitHub、合并或公开发布。

## 界面与默认行为

- Web 保留聊天、Space、展示窗口和连接/偏好/数据小设置面板；原生 modal 保留聊天草稿与 owner，键盘焦点停留在面板内。
- 手机保持聊天和纵向 Space，不创建电脑 owner/画布数据库；首次配置仍在电脑。APK 0.1.6 / versionCode 7，开发签名，交付包不含调试权限或测试 CA。
- 本地启动器改为紧凑服务面板，移除营销、推荐模板、重复状态。保留模型准备/启停/取消、下载状态、语音与真实错误。
- 移除失效商店入口、假头像和无依据的预填值。提醒编辑不再默认填五分钟；失败保留草稿。重命名可取消；清空绑定打开确认时的空间/owner，落盘后才报告完成。
- 使用 REA UI Library Hark `26ac2724f29b4ee46962146fed2b6d545bf62180` 的字体、SVG、连续圆角、透明表面和天空，沿用 shadcn/Radix 等现有基础组件。来源研究仍有其已记录的 partial 边界。
- Vivic 球新增极光/晴空/薄荷/蜜桃配色，随偏好保存并同步展示页；减少动效会同时停止内部 CSS 转动。
- 唤醒默认关闭；开启偏好后，在聊天页主动开始一次前台监听。首次只按需准备 KWS/VAD，云端识别不下载本地 ASR；打开设置不再自动下载三个语音模型。唤醒、识别、停止和失焦状态与球及语音互斥一致。

## 决策与真实执行

新增版本化 Jev v2 任务状态、动态目录、下一步判断、冻结澄清、内容/工具结果续轮和成功回执。旧七标签接口保持兼容；线上可通过部署配置接远程决策服务，全在线用户无需启动器。

桌面和手机共享 owner 执行循环：校验所有目标与整批修改 → 执行 → 等待数据库保存 → 发回执行回执 → 继续后续步骤。支持现有卡片创建/编辑/删除、聚焦/总览/恢复和便笺展开，新增受控相对移动、固定/解除固定、双向传送、整理布局、撤销删除及普通计时暂停/继续。日期/条件/重复计时不会伪装为普通暂停操作；通用编辑历史撤销尚未实现。

相同 executionId 不重放；记录保留超过服务器任务生命周期，容量满时拒绝新增而不丢弃活跃回执。执行后的保存或网络不确定不会进入离线解析再次修改。手机用同步 withCommit 绑定自身版本变化，外部修改、撤权、owner 变化和取消不会被冒认为自己的提交。

实际浏览器检查发现并修复了两处仅单测组合不足以暴露的问题：可见卡片创建后自动唤醒展示页；owner 同步发布已接受的版本，保存完成仍单独等待 flush。单步反馈保留实际结果，不被泛化为“已完成”。legacy 降级仅复用旧解析器的澄清候选，不自动执行其返回动作；native 候选按冻结编号提交原任务。
