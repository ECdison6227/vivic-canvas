# 手机改为两页遥控，电脑设置精简

本轮按用户纠正的产品边界实现：首次安装、模型和服务连接在电脑完成；手机扫码后作为已有电脑工作区的遥控。保留最新 Hark 视觉，不把桌面完整功能搬到手机。

## 手机实际界面

- 聊天：底部输入、实际指令与执行反馈，保留待处理、取消、失败重试、结果未知时查询；不把中继送达说成执行成功。未发送草稿在切页和关闭设置后保留。
- Vivic Space：聊天向右滑进入，向左滑返回；顶部两个 Tab 可直接切换。卡片按单列从上到下显示，不挂载 React Flow、不传自由坐标，不成为另一个 owner。保留当前画布选择和受控固定。
- 设置：顶部齿轮打开次级 sheet，只放手机明暗、字号、同步/重连、断开和撤销授权。服务地址、API Key、语音模型、卡片安装和数据管理在电脑设置。生产不渲染中继地址输入；仅 loopback 开发构建有折叠调试入口。
- 删除旧五项底栏、任务模板入口、独立历史页面和设备管理大面板。执行记录直接留在聊天，不删除已有电脑数据。

两页 DOM 持续挂载并分别保存滚动位置。横滑需单指、足够水平位移；竖向滚动、表单、链接、表格横滚、图表、多指和弹层不触发切页。Android 返回先关闭设置/扫码等层，Space 返回聊天，再由原生窗口处理后台。

## 卡片内容同步

原手机只拿标题摘要。本次共享协议添加严格、可选的可见内容预览，真实手机连接由电脑端显式启用；独立 adapter 的默认仍为摘要，避免改变其他调用者的授权范围。

只投影已知卡片 renderer 使用的字段：文字、清单状态、表格值、数值、图表点和时间安排等；Office 三种卡须经过宿主已安装定义与 builtin 身份/散列核对。未知扩展保留标题与电脑查看提示。不传原记录、模型凭据、来源原件、坐标、偏好或任意扩展对象，不执行服务端 HTML/脚本。

32 KiB 帧限制与原三类操作权限保持。超限先减少末尾预览，再裁摘要，保留当前画布及导航并明确提示同步不完整。图片/故事/封面当前只同步文案，不传媒体；动态 canvas feed 只标题；计时器为同步时点余时。它们不冒充手机端完整媒体/实时计时能力。

手机不建立画布数据库，执行和保存继续走电脑 owner、版本检查与持久化。补齐远程地点查询的可见回答，不为只读回答制造或保存卡片。

## 电脑设置

主导航收为四组：模型与语音、外观、手机连接、更多。默认进入配置；本地能力、卡片/提醒和工作区数据放在对应折叠项。移除原“开始使用”宣传、订阅占位和重复配置步骤。

切组只改变可见性，provider、owner 订阅和未保存字段持续挂载；保留高级项深链与焦点返回。手机连接页先说明电脑配置和可见内容分享，再生成一次性二维码。
