# Hark 组件与视觉全面接入

用户最新要求以 library 新 Hark 为唯一 UI 来源，替换此前 TODAY/Hark 混合版本。本轮覆盖本地启动器、聊天与画布、展示窗口、卡片、设置和安卓控制台。既有业务数据、模型连接、二维码信任校验、owner 确认、编辑保存、撤销与持久化路径保持；不增加 Hark 的账号、购买或服务端功能。

## 来源和直接复用

固定来源 `ECdison6227/rea-ui-library@26ac2724`，入口 `platforms/web/hark/design-package.json`、`DESIGN_SPEC.md`、`ADAPTATION_GUIDE.md`。这是 2026-10-22 新上传的标准包，已经替代上轮 `d7f718d1` 的历史条目；其原版研究仍为 partial，不能把 Vivic 验收冒充 Hark 原站全功能验证。

共用实现位于 `apps/web/src/components/hark/`，源路径、散列与加工方式见 `SOURCE.json`：

- GT Standard L 400/500/600/700、Hark Serif 300/500、GT Standard Mono 400，共七份原文件按原字节接入；15/19 正文、20/26 预览标题、14/20 代码、32/42.24 设置标题使用对应角色。中文按平台字体回退，不声称这些字体包含中文字形。
- 74 个原命名 SVG 的 `decodedBody` 几何直接提取，16×16 viewBox、currentColor 和原填充保留。只移除 SVG 节点间的无意义文本空白；语义别名属于目标映射，具体领域中没有来源对应项的图标保留现有 Lucide。
- 原连续圆角 helper 原字节接入，React/ResizeObserver 是薄包装；fill 和 stroke 分层裁切，根元素不裁工具栏和焦点环。尺寸取布局 border box，避免 React Flow 缩放后曲线被二次缩放。
- 原主题 CSS 每种主题的 66 条核心声明原样保留，只加工选择器。regular、solid、user、agent、composer、stroke 分层使用，普通消息不统一叠加 blur50。
- 原天空着色器、LUT 和 CPU 场景在隔离离线宿主渲染成两张静帧：冻结日期、地点和天气；目标运行不访问天气、不取定位、不创建天空 WebGL。12 种原 Vivic 配色作为轻柔叠色继续同步。该冻结选择为 D，并非原 Hark 自动天气逻辑。

TODAY 的组件、CSS 与旧桥接样式已退出产品源码；历史内容留在本机忽略的 `.cache/hark-full-rework/retired-today/` 以供回退。17 条原业务模板作为现有内容数据保留，交给 Hark 组件渲染，不再导入 TODAY 布局或样式。

## 交互和业务保持

- 启动器保留准备、启用、停止、清理确认、轮询和竞态保护。选择模板只填草稿，不提交模型请求。
- 七组设置持续挂载，导航只移动滚动位置与焦点；切回聊天保留未发送内容。
- 卡片维持原 Schema/定义散列、owner 编辑、固定坐标、聚焦、传送、撤销、刷新恢复和保存反馈；计时器仍只显示数字。
- 手机保留可信扫码地址、确认配对、执行结果未知时禁止重复操作、电脑 owner 离线禁用、撤权和保存语义；输入法出现时收起浮动导航。
- 修复画布重新挂载时相机归零的问题：按本窗口的 Display viewKey 保留短期视图缓存，等待 React Flow 初始化后再记录聚焦前视图；不同画布/owner 隔离，不改同步协议。原聚焦恢复断言保持，0.5/1.4 缩放后精确恢复通过。
