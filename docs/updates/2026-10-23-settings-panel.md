# 设置小面板

用户选择在聊天页内打开小面板。本轮继续线上优先，只更新本机预览和可部署源码包，不发布、不推送；原有本地安装服务不重启。

## 体验

打开本机线上预览 `http://localhost:18794`，完成或跳过新手引导，点击左上角设置图标。

- **连接**：未连接时显示 StepFun Key 输入；连接后只显示名称和真实状态，模型选择和断开操作收在“管理连接”。
- **偏好**：主题、背景入口、语音输入和回复开关。背景配色、定时明暗、字幕、动效、语速、音量、输出设备和通知按需展开；开启语音回复后显示音色和试听。
- **数据**：导入、导出备份；清除数据仍有独立确认。位置管理和重看新手引导保留在此。
- **Space**：聊天顶部入口管理空间、卡片包、卡片布局、固定状态、子卡片及提醒。快速找卡保留独立图标和 Ctrl / ⌘ K 快捷键。

聊天与配置编辑器持续挂载。关闭设置、切换分组、重看引导不会清空输入草稿或重建 owner。支持关闭按钮、Escape、点击面板外区域；Tab 在可见控件之间循环，关闭后回到原入口。折叠详情中的控件不参与焦点循环。模型菜单和清除确认沿用现有 Radix 组件，挂在原生 dialog 的顶层内部。

## 设计来源与适配

沿用 `ECdison6227/rea-ui-library@26ac2724` 的 `platforms/web/hark`，不重新研究原版，不采用 TODAY UI。

| 来源规则 / 组件 | 本轮落点 | 处理 |
| --- | --- | --- |
| GT Standard L、原 glyph、原深浅 alpha tokens | 设置文字、关闭/详情/声音等图标和状态 | 原资源直接复用 |
| 连续圆角、fill/stroke、透明材质 | `HarkSurface` 小面板 | 既有组件复用，背景模糊 50px |
| 既有 Radix / shadcn 选择器、开关和确认 | 模型、语音、主题、清除数据 | 薄包装，核心动作和反馈保留 |
| 分组行与按需详情 | 连接 / 偏好 / 数据 | **D：Vivic 信息组织适配** |
| 原主题材质过渡 | 深浅切换 | 保留来源时长，最终截图等待实际过渡结束 |

460 CSS px 最大宽度、紧凑标题、原生 modal 外壳和三组导航均为 D 目标选择，不声称是 Hark 原版设置的逐像素复刻；来源研究本身仍为 partial。

## 改动映射

| 原位置 | 新位置 / 行为 | 原因 |
| --- | --- | --- |
| 全屏设置与侧栏、重复大标题 | 聊天背景上的一个小面板 | 保留上下文、缩短操作距离 |
| 常驻 Key、断开和模型配置 | 未连接显示 Key；连接后展开管理 | 避免成功连接后仍展示整张表单 |
| STT / TTS 服务选择和重复开关 | 语音输入 / 回复开关，详细参数折叠 | 线上默认 StepFun，减少技术选择 |
| 十二个常驻配色 | 当前配色入口，展开后保留全部配色 | 减少首屏占用 |
| 设置里的卡片、提醒、空间和布局操作 | 聊天顶部 Space 管理 | 操作与对象放在一起 |
| 清空当前画布、撤销删除 | Space 的空间操作 | 数据设置专注备份与清理 |
| 本地能力、手机连接主分组 | 本地构建连接页的折叠项 | 保持原能力可达；线上构建继续排除 |

## 验证与边界

全量 Web 单元测试、线上生产构建浏览器流程、本地构建兼容流程和类型检查已执行，结果见交付更改说明。覆盖草稿和 owner 保留、Tab 循环、Escape / 点击外部关闭、原生模态内的 Radix 菜单和确认、深浅主题、390px、重看引导，以及真实内置便笺和固定动作。

模型状态 / 验证使用明确的测试响应，未调用真实模型或音频服务；未采集物理麦克风、未播放声音。未做服务器发布、Docker / Linux 运行、账号或云同步验收。原有构建的 Sherpaw WASM、外部模块和大 chunk 提示仍保留。

主要入口：`control/SettingsExperience.tsx`、`CompactVoiceSettings.tsx`、`SpaceTools.tsx`、`ControlOverlayContext.ts`，集成在 `ControlApp.tsx`；原有 host、持久化和 Action 校验链路不变。
