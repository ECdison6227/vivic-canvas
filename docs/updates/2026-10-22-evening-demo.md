## 交付边界

安卓是原生扫码加内置 Web 控制界面的混合 App，开发签名演示包，尚无真实手机光学扫码/完整 IME 验收。当前模拟器 ANR 栈指向 QEMU GL 管线，不能据此承诺所有实机表现。

Windows 沿用固定 llama.cpp / Qwen 0.5B CPU 方案，不增加 Ollama 重复运行层；本地决策只做受限意图评分，不负责生成复杂内容，保留保守阈值与回退。

Travel 是明确标注的离线 DEMO。没有真实票价、库存、预订或已接入的飞猪 MCP；专用 Key 到位后还需验证 transport、鉴权、tools/list 与实际响应再实施适配。当前没有把私有 Key 放到前端。办公卡片也未自动同步外部飞书日历。

飞书 CLI 读取被本机 authsidecar 兼容问题阻断，编译工具又被 Windows 应用控制策略阻止；未关闭策略或绕过隔离。设置依据此前已保存的两场原始会议记录。比赛公开信息另核对 [阿里云官方活动页](https://opc.aliyun.com/feizhu)，线上提交截止为 10 月 25 日；未替用户报名、提交或推送仓库。
