## 已实际完成

- 固定引擎 ZIP、Qwen GGUF 校验大小与 SHA-256；受控运行器校验解压文件，实际完成启动、健康检查、预热、推理及停止。
- Windows ZIP 从生产依赖部署生成，无需开发环境。另行解压后重定位，确认无 reparse point/符号链接；实际运行安装脚本复制到用户 LocalAppData 并创建快捷方式。实际执行 Start/Stop 入口；18787 可加载设置、通过服务端同源鉴权桥启动模型，等待后端 ready 与界面「已启用」均出现，再停止回到 cached；`/mobile` 无 owner；页面无 JavaScript 异常。API 强制退出测试中，所属 llama-server 从 1 变为 0；常规停止后 API 不再监听。

- `VIVIC_LIVE_MOBILE=1 pnpm --filter @vivic/web test:e2e mobile-owner-live.spec.ts` 通过：隔离电脑 owner + Display + 独立手机浏览器 context，经真实公网 WSS 中继，扫码 fragment 自动配对并清除、摘要不含卡片正文、手机不打开 IndexedDB、固定卡片保存/同步、文字便笺创建/Display 刷新仍存在、切换画布、撤销手机与停止连接。使用 Chromium 手机视口，非实体手机证据。
