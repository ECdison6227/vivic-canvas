# Project Checklist

## Definition

- [ ] Goal, non-goals and measurable acceptance criteria are written.
- [ ] Inputs, outputs, constraints and sensitive-data handling are defined.

## Reproducibility

- [ ] Setup, format, lint, test and build commands are correct in `project.json`.
- [ ] A clean checkout can be configured from documented steps.
- [ ] Git has an initial commit before Codex worktrees are used.

## Delivery

- [ ] Final artifacts are in `outputs/` and were opened, rendered, executed or tested.
- [ ] Known limitations and recovery steps are documented.
- [ ] Large files have an explicit versioning or storage policy.

## Lifecycle

- [ ] README reflects the current lifecycle and next action.
- [ ] Paused/archived projects record final state, reason and restore instructions.
