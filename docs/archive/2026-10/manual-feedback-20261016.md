## 现在的行为

| 输入 / 操作 | 修正后 |
| --- | --- |
| `上海天气` | 从地名提供方的行政信息识别上海直辖市，直接查询真实天气；不再因浙江/云南同名小地方追问。北京/天津/重庆适用相同规则，真正的同名城市仍澄清。不按结果顺序、人口或 GPS 猜坐标。 |
| `给我创建一个表格` | 立即创建零数据行的空表格，保留「名称/数值」列；没有虚构数值。随后输入 `周一3，周二5，周三4` 可填入唯一/已聚焦的空表格，同一稳定 ID，不另建副本。 |
| 分次添加 `30秒后提醒我喝水`、`45秒后提醒我休息`、`60秒后提醒我开会` | 同画布未固定的带事项提醒，共用一个容器，各行显示事项与独立剩余时间；每条记录的 ID、期限和暂停状态保留。 |
| 到时 | 已交付的一次性提醒行退出 Display，最后一行完成后容器消失，刷新不恢复零秒框。历史记录仍留 Control，用于到时记录及画布条件；重复提醒继续显示下一次时间。纯无事项计时器保持数字显示。 |
| 固定提醒 | 固定项单独显示、保持坐标，不为合并移动它；新提醒仍进入未固定列表，解除固定后可加入合并。 |
| `删除所有卡片` / `删除全部卡片` / `清空画布` | 明确范围只作用于当前画布，直接走本地批量 Action，无需 GPT/StepFun；一次「撤销」恢复整批，包括超过 12/50 张的场景。否定/不明确目标仍不会猜删。 |
| 取消/新指令 | 清掉旧的删除候选及数据建议，不把新指令结果和上一次删除澄清混在一起。 |
| `60分钟后提醒我合并资料` | 不再把事项中的「并」单字误当成额外操作；真正复合/否定要求保持校验。 |

这是用户对原「Countdown 一律仅数字」的明确调整：纯计时器仍数字；事项提醒必须看得出事项，默认合并。新行为已同步根 AGENTS/交接，不应在后续任务中按旧规则退回。

提醒只改变展示投影，不把几个数据记录揉成一条字符串。布局避让、镜头聚焦、拖动和 Orb 避让使用同一投影；拖动列表通过原有 owner 验证移动未固定成员。隐藏的已完成计时记录不再参与画布布局或普通指代/模型上下文。模型不能自行写调度状态。批量删除使用校验后的 `cards.delete.targetIds`，避免绕过单个 ActionEnvelope 的 12 动作上限，仍支持归组撤销。
