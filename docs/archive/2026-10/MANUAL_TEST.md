## 准备

1. 打开 [控制页](http://localhost:5173/control)，保留一个可写主控窗口。
2. 点「新建画布」，重命名为「验收测试」，避免操作原有内容；点「打开 Vivic 展示窗口」。Control 和 Display 使用同一浏览器、同一地址域名，不混用 localhost 和 127.0.0.1。
3. LLM 先选 StepFun Coding Plan，确认已连接。**TTS 保持关闭**，先只测文字和画布；不需要开麦。
4. 若切 Agent 后服务仍运行，不用再启动。后端重启后 Key 会被清除，只需在 Control 重连；不要把 Key 写进反馈、截图或文件。

## A. 提醒、指代与基本操作

按顺序输入；删除时长的两条尽量在创建后立即执行。

| 顺序 | 输入或操作 | 预期 |
| --- | --- | --- |
| A01 | `八分钟后提醒我喝水，十分钟后提醒我休息，十三分钟后提醒我开会` | 生成三个提醒。Display 一张提醒列表显示三条事项及剩余时间，Control 分项管理；到时行退出画布。 |
| A02 | `删除那个倒计时13分钟左右的` | 只删除开会提醒；不能只按左/中/右猜，不能删喝水或休息。 |
| A03 | `撤销` | 开会提醒恢复一次，不重复。 |
| A04 | `删除8分钟左右的倒计时`，随后 `撤销` | 只删除/恢复喝水提醒。若测试拖延很久，改用「删除喝水提醒」。 |
| A05 | `添加待办：整理资料；回复邮件；完成测试` | 一张待办卡含三个条目。 |
| A06 | `把待办第二项标记为完成` | 只有「回复邮件」显示完成状态。此项走本地规则，应无需等待模型；失败请记录反馈。 |
| A07 | `聚焦待办`，随后 `恢复原视图` | 只改变镜头，卡片内容/密度不变。 |
| A08 | 在 Control 提醒列表暂停喝水，等几秒，再继续；修改为从现在起 0.2 分钟 | 暂停期间剩余时间不变；恢复继续；修改后约 12 秒出现到时字幕/柔光，最近到时只记录一次，TTS 关闭时不出声。 |
| A09 | 再建一张待办后输入 `删除待办` | 若没有明确焦点/唯一目标，先澄清，不能任意删除；选择目标后只删选中的一张。 |

## B. 天气、搜索和数值图表

| 顺序 | 输入 | 预期 |
| --- | --- | --- |
| B01 | `上海天气` | 上海直接显示真实天气温度/图标；真正同名城市才提示选择；无网络则两端诚实报错。悬停天气可查看 Open-Meteo/GeoNames/许可。也可直接输入完整限定城市。 |
| B01a | `给我创建一个表格`，看到空表格后回复 `周一3，周二5，周三4` | 立即创建空表格，不凭空填数；补充后在同一张表格填入 3、5、4。 |
| B02 | `用表格记录：周一3，周二5，周三4` | 一张表格，数值依次 3、5、4。 |
| B03 | `把这张表格画成柱状图` | 新图表使用同一组 3、5、4，不能改数或凭空补数据。此时应只有一张目标表格；有多张时要明确目标。 |
| B04 | `把这组数据画成折线图：周一3，周二5，周三4` | 真实 Recharts 折线，值仍相同。 |
| B05 | `画成饼图：苹果3，香蕉5，橙子4` | 非负数据饼图。再试 `画成饼图：收入3，支出-2`：应澄清，不取绝对值伪造比例。 |
| B06 | `搜索 React Flow 官方文档` | 带可点击真实来源的搜索卡；刷新后来源保留。不要把“搜索摘要”当作已阅读全文。 |
| B07 | 搜索等待时点取消；或立刻发 `显示全部` | 思考状态应清除，迟到结果不能擅自改画布。 |

## C. 便笺、排版、持久化和双窗

先输入下面一整条（可复制）：

```text
创建一张便笺，完整保留以下内容：今天先整理项目需求，逐项检查每一个提醒是否对应正确的事项；随后核对天气和搜索来源，确保没有把示例数据当成真实数据；接着检查表格转图表后数值是否一致；最后记录重叠、聚焦、撤销和刷新时遇到的问题，保留复现步骤交给下一轮开发。
```

| 顺序 | 输入或操作 | 预期 |
| --- | --- | --- |
| C01 | `展开这张便笺`，再 `收起便笺` | 展开可看更多原文，收起变回简短视图；数据不被总结改写。多张便笺时先选择。 |
| C02 | `显示全部` | 现有不同大小卡片均在视野内，卡片主体及未裁切长文本不能互相覆盖。 |
| C03 | 将展示窗口缩到约 800×600，再输入 `显示全部` | 自动缩放，小窗口仍能看到全部；不以删卡或改数据解决拥挤。 |
| C04 | 在 Display 拖动一张卡，随后刷新 Display | 位置保留。手动可自行摆到重叠；输入 `重新排布` 应整理未固定卡片。 |
| C05 | 在 Control 固定一张卡，再新增卡片并 `重新排布` | 已固定卡片保留坐标，自动卡避开它。两张固定卡本身重叠时须先解除其中一张固定。 |
| C06 | 删除一张卡，`撤销`，刷新 Control 和 Display | 恢复卡数据/来源，不能重复、漏卡或再次重叠。 |
| C07 | Control 主题切浅/深/自动，修改白天开始/结束时间；开关减少动效和字幕 | Display 同步；自动时段按本机时间生效，可跨夜；主题/设置刷新后保留。字幕关闭也应隐藏思考文字。 |
| C08 | 导出 JSON → 新建画布 → 导入该文件 | 导入为另一张画布，卡片、来源、位置恢复；文件不含任何密钥/图片字节。 |
| C09 | 在另一张画布创建 0.2 分钟提醒，切回验收画布并等待 | 仍收到到时提示，当前画布不被强制切走。 |
| C10 | 打开第二个 Control | 应显示只读；只有明确接管后才能写，不能两个窗口同时回写不同布局。 |

独立空白测试环境中可选验收：先导出需要保留的画布，再在「本地数据」点「清除全部本地数据」。取消时数据不变；确认后只剩默认空画布，显示/语音偏好复位、TTS 关闭、语音模型需重新下载，已打开的其他 Control/Display 同步清空，刷新或接管不能恢复旧内容。此操作无法撤销，会影响同一浏览器同源下的全部画布，请勿在仍需保留数据的环境直接确认。

## D. GPT 与图片（保持静音）

1. 切换 GPT；若未连接，使用已有本机授权恢复。新的本人授权已于 2026-10-16 完成，不必为了本次测试注销 Pi 或重复登录。
2. STT/TTS 都可关闭，重复 A01、B06，确认 GPT 可以独立完成提醒和搜索。
3. 准备一张你愿意发给模型的 PNG/JPEG/WebP 算式图片，先选择附件，此时不应自动分析；输入 `读出图片里的算式，计算结果，创建一张简短便笺`，明确发送后才处理。支持上传、拖入和附件区域粘贴；一次一张，最大 4MiB。
4. 刷新 Display、导出 JSON，图片预览/字节不应成为画布卡片或导出内容；结果便笺可以保留。
5. 如选 StepFun 做图片测试，先选支持视觉的 `step-3.7-flash` 或 `step-5-preview`（以实际账号权限为准）。默认 `step-3.5-flash` 不按视觉模型处理；无视觉权限时应明确拒绝。
6. 切回 StepFun，不应擅自开启 TTS 或改掉独立语音选项。

## E. 语音（单独选择测试时机）

新增功能仍需本人允许发声后再测：开启语音反馈，较慢指令约 300ms 后可有一次「我看看」，超过 5 秒可有一次「稍等」；取消或新指令必须停止短句，快速规则结果无需先播提示。另勾选默认关闭的「请求逐词字幕」后，真实 StepFun 返回匹配词轴时字幕按媒体进度高亮，否则整句显示；服务拒绝时关闭该项恢复普通语音，不会自动重试。预录/云音频的 Orb 可随音量轻微变化，静音/暂停/结束时归零，减少动效时不做振幅变化。系统本地音色只在浏览器给出有效 boundary 时高亮，不能假装测到了系统声音的 PCM。自动化已用静音替身覆盖，尚不代表实际听感通过。

- **PTT 不需要开启 TTS。** STT 选 StepFun Plan ASR，按住「按住说话」，说「十分钟后提醒我喝水」，松开后先检查转写再发送。第一次权限弹窗后需重新按住。取消/拒绝权限时文字仍能用。
- 本地识别：按需下载 ASR；唤醒链路另需 VAD/KWS。切 STT 为本地，重复上面一句。模型下载取消后不能冒充成功，清理缓存后要重新下载。
- 本地唤醒是显式前台单次入口：开启后说「你好维维」，再说一条指令。说完需再次开启；切走标签页或失焦会停止。默认唤醒短语的本人声学命中/误唤醒还未验收，失败请单独记录，不等于文字功能失败。
- **只有现场允许发声时**再勾选 TTS，选音色、低音量试听并检查语速；看 Orb/字幕是否随真实播放开始和结束。切换 LLM 不应混淆语音服务，其他 Display 不应重复播放。办公室继续保持关闭。

## 本轮新增（按需在本人画布操作，自动化不代做）

- `显示全部`、`把待办第2项标记为完成`、`暂停喝水提醒`：精确操作即时执行；不存在的事项名不应改动其他提醒。
- `每天09:00提醒我喝水`、`每周一、三、五下午3点提醒我休息`、`明天上午9点提醒我开会`、`纽约时间2026-12-01 09:30提醒我开会`：Control 有计划/时区；有事项的 Display 显示事项及时间，纯计时器只有数字。
- `当待办第1项完成后5分钟提醒我休息`：先等待，再在真实条目完成后计时；不存在/多目标则澄清。
- `读取 https://example.com/`：显示真实正文摘录和来源；私网链接拒绝，截断不称全文。
- Control「本地快速决策」准备/启用/停止：默认关闭。Kev 是中文小范围实验，不确定时放弃；固定规则已经可以跳过 LLM，无需为了规则命令启用模型。
- 输出设备、静音通知、Plan 复刻均需本人主动操作。复刻使用已有 File ID 和声音使用授权，不录音/上传、不自动试听；真实权限/设备效果另行验收。纯 Web 无法在浏览器全关闭后保证准点通知。
