## 原计划：统一清除本地数据

沿用 Control「本地数据」和 Radix 确认弹窗，新增「清除全部本地数据」。仅主控可执行，清除前取消请求与语音、等待已接受的画布保存和在途提醒交付。一次 IndexedDB 事务替换画布及元数据，清空撤销/提醒/偏好，清理所有语音模型缓存（含旧/损坏记录）并让旧下载 lease 失效；其他 Control/Display 同步，旧展示链接刷新后回到默认空画布。清理期间阻止新写入，被接管或缓存/存储失败时明确报错，已接受的创建、改名和偏好写入不能因失败而丢失。

账号连接及 Pi 安全存储不在清除范围；测试只确认独立测试环境，未清除用户真实数据。模型缓存与画布处于不同数据库，清理无法跨库原子提交：若模型清理成功、随后画布事务失败，模型需重新下载，画布事务保持原内容，界面报告未完成。

WebKit 首次测试在准备 Blob 缓存样本时出现 `UnknownError: Error preparing Blob/File data to be stored in object store`，尚未触发清除操作。失败录像/上下文保留于 `evidence/next-iteration-local-data/webkit-fixture-failure/`；改用包含 Uint8Array 的损坏/旧记录后清除测试通过。本轮不据此声称 WebKit 的真实语音模型 Blob 下载/缓存已验收。TEST 截图/录像保留在同级各浏览器目录。

仍未完成的原计划细节：合法预录短反馈、逐词时间线及声音振幅反馈；本人麦克风/唤醒词、物理 Safari/外接屏和最终长期性能基线仍需现场验收。没有扩展 LLM 接入方式，也没有改写已完成卡片模块。
