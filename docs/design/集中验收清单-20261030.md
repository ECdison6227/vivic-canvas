# 回来后一次测完

按你2026-10-30的最新安排，开发和自动验证先推进，下面这些亲试项目集中留到最后。这里没有勾选的项目不表示自动测试失败，表示还需要你在自己的设备上体验。

入口：[Vivic](https://vivic.edsionc.top/)。先登录、在设置里确认自己的模型已连接，再用一个单独的测试Space。将聊天页和展示窗口并排打开。

## 基本使用

- [ ] 说“倒计时50分钟”，看到一张50分钟计时卡。
- [ ] 说“添加待办：买菜、交周报”，两项都出现。
- [ ] 说“帮我记个便签明天交周报”，内容和期限保留。
- [ ] 说“显示全部”，再说“恢复原视图”，卡片内容不被修改。
- [ ] 说“帮我记个便签出门带钥匙，再设个10分钟倒计时”，两项都完成。

## 追问和删除

- [ ] 有两张便笺时说“聚焦便签”，看到候选后回复编号，选中的卡片与编号一致。
- [ ] 说“删除读书笔记”，先回复“算了”，确认原卡片还在。
- [ ] 再说“删除读书笔记”，回复“确定”，只删除指定卡片。

## 回答与图片

- [ ] 说“介绍一下Google，做张知识卡”，检查标题、摘要、要点和文字可读性。
- [ ] 从“＋”上传交付的 `g-demo-colors.png`，说“分析左右两块色块的颜色，并保留图片”，核对左蓝、右橙，以及卡片里的原图。
- [ ] 刷新页面后，图片和卡片还能打开。

## 你自己的卡包

- [ ] 设置 → 数据 → 卡片包，导入 `fitness-log-v02.vivicard`，看DEMO后确认安装。
- [ ] 说“今天练了40分钟背”，检查实际当天日期、背、40分钟。不要采用DEMO里的旧日期、腿、25分钟。
- [ ] 说“今天练背”，应询问时长；说“今天背部训练900分钟”，应说明范围，不能擅自换成其他数字。
- [ ] 停用后数据仍保留；重新启用后恢复显示。
- [ ] 下载后重导入相同卡包，不重复安装同一版本。
- [ ] 卡片仍引用该版本时，卸载被阻止。清理测试卡片后，再卸载测试包。

## 设备体验

- [ ] 在自己的手机浏览器登录同一账号，核对输入、滚动、卡片内容和卡包管理。
- [ ] 深色、浅色下都能读清卡片与设置文字；自动截图的窄屏检查不能替代实体手机体验。
- [ ] 如需测语音，由你主动开启麦克风和声音，检查识别结果、回复和停止。自动验收保持静音，没有代替这一项。

## 反馈与后续

有问题时保留测试序号、原话和截图，方便按同一输入复现。所有步骤均在测试Space完成，最后只清理该Space里的测试卡片和包。

维护者的十条演示话术和预期效果见 `DEMO.md`；原始评测、实际截图与剩余边界见G阶段报告。NoteCard/NewsCard逐条高亮、候选列表直接点选，以及一周真实使用数据，按交接单单独列明状态，不默认算作已经亲试通过。
