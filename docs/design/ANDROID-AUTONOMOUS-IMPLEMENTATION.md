## 实现决定

- 沿用批准的 Kotlin/Compose 原生两页设计、现有 Cookie/Space/任务协议和服务器 ASR/TTS。
- 我选择在后端的纯模型推理边界做 StepFun→DeepSeek 回退，不重复提交任务或持久化命令；取消请求不回退。固定官方 DeepSeek 地址，密钥按账号短期隔离，不进入网页存储或日志。
- 网页和手机的模型连接都放在设置中。StepFun 优先，DeepSeek 可单独连接并用作回退。手机上的私有连接数据用 Android Keystore 加密并按账号隔离。
- 网页以部署时最新资源为基线，使用独立扩展模块和精确改动集；保留同事新增的样式、背景、语音与交互。发布前重新校验基线并备份，发生并行改动则重新生成补丁。
- SSE 统一 Space 变更通知；大屏聚焦、熄眠/唤醒使用账号隔离的临时命令及确认回执。无确认不改变手机开关状态。
- 原计划的引用功能保持 P0 核验限制，直到明确目标契约可验证；其他范围按原计划完成。
- 不再向用户询问常规技术选择或请求阶段验收；无法实测的物理手机/麦克风边界如实记录，不用模拟结果替代。
