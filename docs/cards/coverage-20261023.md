# 官网与产品卡片覆盖表（2026-10-23）

本表以官网 `https://edsionc.top/vivic/`、仓库 `landing/demoCards.ts` / `SceneRing.tsx`、共享 `SCENES`、产品 `cards/registry.tsx` 交叉核对。官网实际浏览由主 Agent 完成；本执行者核对源码、真实组件、契约和定向自动化，不将源码检查记作浏览器视觉通过。

**25 个轮播展示项 → 24 个不同类型；21 个内置场景；产品共 26 个 renderer。** 日期倒数和纯计时共用 `CountdownCard`。另外两个 renderer 是 `NoteCard` 和 `ExtensionCard`；三个办公包是 ExtensionCard 的已验证定义，不是三种新卡片协议。`landing/shared.tsx` 的 CardFrame 最终调用真实 VivicCard，未新建静态演示卡。

## 验证口径

- **A**：本轮运行 API `scenes.test.ts` / `office-planner-packages.test.ts`，实际 parser/builder/grounding 与受控 fixture 模型；不表示真实联网服务或模型效果验收。
- **R**：本轮运行 `sceneCards.test.tsx`，21 个场景与边界样例在 Control/Display 中使用真实 renderer；经典类型另见 `dataCards.test.tsx`。
- **P**：新增 `cardCoverage.test.ts`，全部 26 类型经过真实 owner 创建、固定、flush、数据库读取、owner 重新打开恢复，displayProps/sourceData 保持；数据库为独立内存实例。
- **M**：新增全官网投影检查，25 项进入现有严格手机白名单；移动组件测试和 adapter 测试验证只读与边界。手机显示投影，不实例化 renderer 或扩展运行时。
- **E**：该行新增行为回归在 `cardPolish.test.tsx` / `MobileCardPreview.test.tsx`。
- 浏览器整体视觉、12 配色和真实聊天链路由主 Agent 统一验收；本表不把现有 e2e 文件的存在当作本轮执行证据。

## 26 个真实类型

所有行均通过 P；Display 均不开放业务编辑。表中“编辑”列只列卡片内现有入口，内容也可通过宿主受控对话/子卡流程修改；没有独立表单不等于注册缺失。

| 类型 / 官网键 | 创建与事实来源 | 实现与现有编辑入口 | 手机投影 | 本轮验证 / 剩余边界 |
| --- | --- | --- | --- | --- |
| CountdownCard / countdown、timer | `countdown` 日期场景；计时/事项提醒另走受控提醒链路 | CountdownDateView、CountdownCardView、ReminderListView；日期表单与提醒宿主管理。纯计时只显示数字；事项显示事项与时间 | 日期文字；严格匹配的既有摘要本地刷新数字；暂停冻结、条件未满足显示等待 | A/R/P/M/E。不匹配或旧格式原样显示摘要，手机不调度、不自行删除到期卡 |
| TodoCard / todo | `todo_list`；用户任务事实 | TodoCardView；添加、完成、删除；Display 前 5 项和剩余数 | 只读勾选列表 | A/R/P/M；不在手机新增完成/删除权限 |
| ChartCard / chart | `data_visualization`；有依据的数值 | ChartCardView + Recharts；已有图型切换 | 原有数列转柱状预览，新增可展开数值表 | A/R/P/M。手机白名单没有 chartKind，保留统一柱状投影，不声称与桌面图型完全一致 |

| GalleryCard / gallery | `photo_gallery`；用户图片 URL / 本地照片引用 | GalleryCardView + MediaImage/Lightbox；添加、删除、题注、放大 | 图片数量和题注，禁止传私有原图 URL/Blob | A/R/P/M；手机为文字投影，未新增照片传输 |

| StoryCarouselCard / story | `photo_story`；用户故事与媒体 | StoryCarouselCardView；分页、文本/照片编辑、增删页 | 标题和各页故事文字 | A/R/P/M；手机不复刻媒体轮播 |

## 代表检查入口

开发模式 `/playground` 继续使用真实注册组件和 schema，仅写该页内存。新增 URL 选择与 Hark 真实表面，修正旧“20 张”的硬编码计数。例：

- `/playground?scene=goal_progress&theme=dark&width=mobile`：大数值、输入/失败草稿、操作换行。
- `/playground?scene=weekly_schedule&theme=light&width=mobile`：无时刻事件与按天纵排。
- `/playground?scene=book_record&theme=dark&width=mobile`：阅读状态、页码、封面。
- `/playground?scene=single_notification&theme=light&width=mobile`：长标题、状态操作和只读 Display。
- `/playground?scene=travel_offers&theme=dark&width=mobile`：DEMO 来源、选择与备注。
- `/playground?scene=edge&theme=dark&width=mobile`：既有长文本/空/缺图 fixture。

`width=mobile` 是桌面卡片的窄容器压力检查，不冒充 `/remote/` 手机协议页面。手机真实投影仍由主 Agent 在配对场景检查。
