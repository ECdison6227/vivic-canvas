## 验收

- [ ] 只管理自己启动的服务，重复启动、端口占用、服务异常、退出清理与重连可复现；不结束其他程序腾端口。
- [ ] Windows/Mac 支持矩阵与实际设备记录分开；Linux测试不代表两平台已通过。
- [ ] 密钥留受控本机后端，浏览器只得到允许的状态/能力；不无鉴权监听公网或使用无约束跨域。
- [ ] 未配置/设备离线时不阻断文字主链路；需要模型下载时显示大小/路径/取消，不默认下载全部模型。
- [ ] 现有 scripts/dev.mjs 只是开发服务启动，不等于面向用户的模型启动器；若修它，另小 PR，不覆盖其他 Agent 的工作。
